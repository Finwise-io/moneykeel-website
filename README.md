# aMoneyKeel marketing website

Static marketing website for moneykeel.ai. No framework or build dependencies.

## Hosting

Cloudflare Pages: connect this GitHub repository, choose **None** for framework, leave build command empty and set output directory to `public`. Then connect moneykeel.ai under Custom Domains.

## Editorial cautions

- The three images in public/assets are historical product **design mockups** from Finwise-io/finwise, not independently validated screenshots of the current TestFlight build.
- The green M shown in the site is a temporary typographic stand-in; replace it with the approved original M PNG when the asset is uploaded.
- No bank linking, public beta registration, or live payment features are claimed as shipped.
- Add approved privacy policy, support contact details and beta link prior to public launch.
- App repository: https://github.com/Finwise-io/finwise

## Preview

Open `public/index.html` in a browser. All assets resolve locally under `public/assets`.
